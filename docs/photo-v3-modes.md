# V3.0 九种摄影模式 · 规则说明

> 交付物第 5 项。状态列：✅ 已在代码中存在（`photo-modes.js`）｜🆕 V3 新增（待实现）
> 所有模式共享：真实手机摄影质感、9:16 竖版、自然生活状态（不固定冷脸）。

## 1. face_closeup 面部特写

- 机位：手持手机举在脸前 20~35cm，镜头正对脸。
- 构图：面部特写（额头到下巴，可带到锁骨）。
- 手：0~1（可托腮/扶脸），**手机本体不入画**。
- 参考图：脸。
- 禁止：手机出现在画面里；出现第二张脸（镜中/屏幕中）。
- intent 触发：`怼脸/面部特写/只拍脸/脸贴镜头`。

## 2. front_selfie 前置自拍

- 机位：手持，举在脸侧或前方，约一臂（40~60cm），略高于眼。
- 构图：头肩 / 半身。
- 手：**1 只（举手机）**；另一只手只能 扶膝/扶腰/自然垂/完全在画外。
- 参考图：脸。
- 禁止：手机本体出现在画面（前摄=镜头就是手机）；两条自拍臂同时伸向镜头。
- intent 触发：`前置/自拍`；兜底 `头肩`。

## 3. half_selfie 半身自拍 🆕

- 机位：前置一臂，略高。
- 构图：半身（到腰/胯）。
- 手：1 只举手机；另一只按上式。
- 参考图：脸。
- 与 front_selfie 的区别只在构图带（到腰 vs 到胸），机位/手规则相同 —— 因此实现上可共用一套规则，只切换 `framing.band`。
- intent 触发：`半身`。

## 4. mirror_selfie 对镜自拍

- 机位：手机对着镜面，人站镜前约 1m；画面是**镜中影像**。
- 构图：全身 / 半身 / 穿搭展示。
- 手：**1 只举手机且必须在镜中可见**（这是"对镜自拍成立"的证据）。
- 参考图：脸（服装**按文字**，因为镜拍最容易被参考图的衣服带跑）。
- 禁止：镜中没有手机（等于有人替她拍）；手机本体出现在画面中央挡住脸。
- intent 触发：`对镜/照镜子/镜前`；`穿搭/这身/新衣服`（未明确指定其他机位时）。

## 5. first_person 第一人称

**五个子型（决定手数与构图）**

| 子型 | 触发 | 手 | 构图 |
|---|---|---|---|
| handheld | 端着/拿着/举着/喝/杯碗筷 | 1 | 上 2/3 物品，下 1/3 手臂 |
| desk_work | 桌面/书桌/键盘/写字/砧板 | 1~2 | 上方桌面物品，下方双手 |
| two_hands | 双手/捧/拧/撕/掰 | 2（左右职责明确） | 双手在下部，物在中上 |
| object_only | 无动作，只记录东西 | 0 | 纯物品 |
| observe | 看窗外/看房间/环境 | 0 | 环境纵深，无人体 |

- 机位：**镜头在她眼睛位置**，朝下 30~45°。
- 可见：只手臂/手（可带一缕头发）；**不出现脸/头/肩/躯干/腿**。
- 参考图：**无**（带整身参考图会被画成第三人称）。
- 禁止：第三人称机位；手机本体；多出第三只手；手与物品没有接触。
- intent 触发：`第一人称/第一视角/POV`（显式）；`桌面/碗里/手里/眼前` + 动作词。

## 6. rear_object 后置拍物

- 机位：后置镜头朝物，通常俯视。
- 构图：物品特写 / 环境照 / 局部（手入画）。
- 手：0~2，若入画必须与物品有接触关系。
- 参考图：**无**。
- 禁止：画面里出现人物（脸/身体）。
- intent 触发：`拍给你看/记录一下/拍下`。

## 7. video_call 视频通话

- 机位：手机架在桌上/靠在水杯边，镜头正对她。
- 构图：头肩~半身。
- 手：0~1。
- 参考图：脸。
- 禁止：出现"另一个人举着手机拍她"（第三方视角）。
- intent 触发：`视频通话/视频里/通话中`。

## 8. scene_only 纯场景

- 机位：后置/环境机位。
- 构图：环境/风景/房间。
- 手：0。
- 参考图：**无**。
- 禁止：任何人体（手/手臂也算）。
- intent 触发：`[场景图:]` 标记；`窗外/街景/风景` + 无人物。

## 9. back_view 背影 🆕

- 机位：镜子反射 或 从身后伸出手机；**不露正脸**。
- 构图：半身 / 全身，背部与后脑为主。
- 手：0~1（举手机那只可不入画）。
- 参考图：体型（**不锁脸**，因为看不到脸）。
- 禁止：正脸；把它当普通前置自拍。
- intent 触发：`背影/后脑/背对`。

---

## 跨模式硬规则（所有模式共享，不允许各自改写）

1. `visible.hands / arms` → `hands.max*` → `audit.max*`：**同一个数，只算一次**。
2. 手机本体是否入画由模式决定（前摄=不入画；镜拍=必须在镜中可见；后置/第一人称=不入画）。
3. 参考图策略：**要看得见脸才给脸参考图**；`first_person / rear_object / scene_only` **一律不给**。
4. 场景里的窗、桌、书、绿植只是 `scene.background`，**永远不参与机位决策**。
