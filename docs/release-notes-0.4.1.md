# WhalePod 0.4.1

一个**修 bug 的版本**。这一版改动比平时的补丁版大 —— 因为它把几件**一直没接上线的功能**真正接上了，也把一块**不再需要的旧东西**拆掉了。

> ⚠️ 这一版**重发过一次**。下面从「B 站/贴吧」到「其它修正」是最早那批，**从「群里分享的视频她不回」往下一整段是重发补进去的**。

# 第一批：B 站、代理、表情包、人格按会话

## 修了：B 站/贴吧/热点全部"取失败"

**症状**：她回「本鱼这边放不出来」，贴吧订阅和热点也全是 `fetch failed`。

**查出来的原因**（不是 B 站挂了）：

```
https_proxy = http://127.0.0.1:7890     ← 环境变量里有代理
NODE_USE_ENV_PROXY = 1                  ← Node 被要求走它
127.0.0.1:7890  ✗ ECONNREFUSED          ← 但代理软件已经关了
b23.tv:443      通                       ← 裸连其实没问题
```

代理软件关了、环境变量还留着，于是**所有请求都往一个死端口上撞**。而 B 站是国内站，本来就不需要代理。

**顺带还发现**：NapCat（协议端）也是 Node 应用，跟着继承了同一份变量 —— 所以那会儿**连发消息都会失败**（`connect ECONNREFUSED 127.0.0.1:7890`）。

**修法**：
- 国内域名（`bilibili.com` / `b23.tv` / `hdslb.com` / `bilivideo` / 贴吧…）追加进 `no_proxy`
- **在 `main()` 最前面做** —— Node 的 fetch 在第一次调用时就建好 dispatcher，之后再改环境变量**无效**
- spawn NapCat 时**剔除**代理变量，并显式 `NO_PROXY=*`

⚠️ 附带一句：**`resolveBvid` 失败不再静默**了。原来它 `catch { return null }`，出问题时日志里一个字都没有。

## 修了：她会编"我点开是想干嘛"

**现场**：视频标题是「你爸回你消息了」，评论弹幕全在聊"大肥鱼/赛博养鱼"。她的回复：

> （看完，先笑了一声）**点开想学修电脑**，结果评论全在要饭。

「点开想学修电脑」在标题/简介/评论/弹幕里**一个字都没有** —— 纯编。

**为什么原来的警告没拦住**：它只禁"聊视频里讲了啥"。而"我点开是想学修电脑"是**编了个观看理由**，模型不觉得那算"讲内容"，而且它比"我没看过"更像聊天。

现在把边界说全了：**连"我点开想干嘛"也不许编。**

## 新增：表情包同类只留 3 张

收藏表情越攒越多，但**同一情绪**的图往往有十几张。池子太大会让提示词清单变长、按标签挑的时候同类互相挤。

现在：**同类最多留 3 张，留最新的**，每打完一批标签就顺手收敛一次。

**"同类"按标签组合的相似度算**（Jaccard），不是按第一个标签 —— 因为库里「无语」打头的有 14 张，但第二标签差别很大。按第一个标签归类会把这 14 张当同类砍到 3 张，等于删掉明显不同的图。

**阈值 0.5 是拿真实库试跑定的**：0.4 会过度合并，0.6 完全不触发。实测 **72 张 → 69 张**。

⚠️ **只清标签库，不删表情本身。**

## 新增：人格可以按会话生效

原来 `persona.active` 是**全局**的。现在可以**群聊和私聊用不同角色**：

查找顺序：**精确会话 → 类型（group/private）→ 全局**。

⚠️ 选「**全局**」会**清掉按会话的指定** —— 不然全局那个值永远轮不到，看起来就像"点了没反应"。

## 其它修正（第一批）

- **被点名时不再给 `[SILENT]` 出口** —— 原来被 @ 了也可以不吭声
- **别人被 @ 时不插嘴** —— 原来只要是问句就强制回答
- **长期记忆不再把她某次拒绝写成"她是谁"** —— 原来摘要会写「我仍拒接荤话」，然后她照着继续拒绝，越写越硬
- **长视频先应一声**：超过 5 分钟的，先回一句，后台只听开头 2MB

# 第二批（重发补进来的）

## 修了：群里分享的视频她不回

**根因**：决策层的判据里**根本没有"分享内容"这一类**。裸链接没 @ 她、不接她的话、也没情绪 → 只能落到 `wait`。实测群里 7 次视频分享，**6 次 wait**。

补了一条 ★「有人分享了视频或内容」，并注明**不受"没 @ 己方"限制**（分享本身就是冲着群里来的）。

实测：分享 0/3 → **2/3 判 reply**，而对照组（普通闲聊）仍是 wait。

## 修了：表情段发不出去（两个 NapCat 怪癖，都实测复现）

**① 单独一个 `face` 段会被拒**：

```
只有 face（数组 / id 数字 / CQ 字符串）  → ❌ 全拒
空文字 + face                          → ✅ 通
face + 空格                            → ✅ 通
文字 + face                            → ✅ 通
只有 image                             → ✅ 通（图不受影响）
```

**② 附件段失败不该中断整条**：原来只有 `image` 是 warn+continue，`face`/`mface` 直接 `throw`。

**两个叠一起出的事故**：B 站长视频的补发里，她**以表情开头** → 第一段就是单独 face → 被拒 → `throw` → **正文一个字没发出去**。
用户看到的是「她没读视频」，日志里只有一句「补发失败」——**两边认知完全对不上**。

## 修了：搜索把私聊内容发出去

**当天 11 次搜索里 5 次是闲聊**，其中两句是**私密内容**（「插进去了吗」「那我们是什么关系」）——**被发给了搜索引擎**，比花钱更要紧。

- 加**隐私闸**：亲密/关系类内容一律不搜（放在"用户明确要求搜索"之后）
- 修 `detectProperNoun`：把「那我们是什么关系」抽成「那我们」当专名 → 加 `isPronounish` 守卫
- 扩 `rhetorical`：「不也…吗」「不都…吗」「不早…了吗」也是反问，不是求知

实测 5 条闲聊 → **4 条不再搜**；对照（CAD / RTX5090 / 黑神话）照旧搜。

⚠️ 顺带补了一个**可观测性缺口**：通过网关（DSH 里用）触发的搜索**原来不记账** —— 钱花了，台账上看不见。现在补记一笔（仍然不限额）。

## 主动发言：拆掉冷却器，改成每 tick 全随机

**冷却器的问题**：它是"发言后掷一次间隔（180~300 分钟）存起来，到点才允许说"——仍然是**定时器**，攒够必然说，只是周期随机。实测她几乎冒不出来，日志整天刷 `群：剩 2 冷却中`。

**现在**：`maySpeakNow()` 每 60 秒的 tick **独立掷一次**，概率 `speakChance`（默认 0.004 ≈ 每 4 小时一次，白天窗口 ≈ 3.6 次/天）。

⚠️ **同一 tick 内只掷一次**（按 60 秒桶缓存）—— `usableScopes()` 一轮里会被调用多次，每次重掷会让实际概率变成 `1-(1-p)^n`，**累积暴涨，又变回"到点必说"**。

## 渠道：初始只留官方那条，自定义渠道与本地模型平铺

**发现一个真 bug**：`deepseek-official` 只由 `createLlmGateway()` 挂载，而那条路要求 `appDir && pack`。**没装 channel-pack 的机器走不到** → 「初始只留官方那条」等于**零个渠道**。

现在直接从凭据取 `DEEPSEEK_API_KEY` 拼一条标准 OpenAI 兼容渠道。没有 key 就不加。

**还修了一个模型名错误**：官方端点 `/v1/models` 只返回 `deepseek-flash` / `deepseek-v4-pro`，而代码里（渠道 + config 默认 `fallback.model`）都写着 `deepseek-chat` —— 那是**老开放平台**的 id，这个端点上 404。**写错的兜底通道等于不存在，而且只在主渠道全挂时才暴露。**

**渠道页现在平铺三类**（用户原话：「magpie 其实算自定义渠道吧」—— 对，它们本来就是同一种东西，只是来源不同）：

| 来源 | 可编辑 | 可删 |
|---|---|---|
| 手填 | ✓ | ✓ |
| DSH 发现 | ✓（存成手填的，同 id 盖住自动发现那条） | ✗ —— 删了下次启动又发现回来 |
| 内置 | ✗ | ✗ —— key 还在凭据里 |

**本地模型**：预置里有 Ollama（`127.0.0.1:11434/v1`，不需要 key）。

**优先级**：手填 → DSH 发现 → 内置。**内置是付费兜底，排最后**（排前面会把你现在用的免费渠道挤掉，等于悄悄涨价）。

## 拆掉 channel-pack（那 14 个免费渠道）

按你的决定：「不用了，现在就用 magpie，算是自备渠道」。

- 删 `src/gateway/llm-core.js`（18.7 KB，整个模块）
- 删 `if (appDir && pack)` 分支 + 不再需要的 `mergeLlm()`
- **删「4b. 免费渠道优先顺序」** —— 这一段是把那 14 个**写进 config.json** 的源头
- 删 4 个依赖它的测试
- `findDshAppDir` 抽成独立模块（`dsh-providers.js` 和 `restart.mjs` 还要用，**不能跟着陪葬**）

⚠️ **有一处故意没删**：`router.js` 的 `DEFAULT_FREE_ORDER` / `PROVIDER_MODEL_HINTS`。它们在某几处是**按 provider 查的通用兜底**（不是"14 个渠道专用"），删表会动到**自定义渠道的模型兜底**。而且它们现在是**惰性的** —— 没有免费渠道存在，查也查不到。**写在表里的名字 ≠ 提供了这些渠道。**

## 路由策略：从装饰变成真开关

面板上一直有个「路由策略」下拉，查下来发现它**根本没接线**：

```
写进配置后谁读它：
  assets.js  按钮高亮 + 一条横幅     ← 纯显示
  /health    原样回显
  路由侧     ✗ 没有任何人读
```

`resolveCandidates()` 读的是 `freeProviders / freeOrder / selfModels / catalog / fallback / disabledProviders` —— **没有 `strategy`**。**点那三个按钮，路由一点都不会变。**

而且它的前提（免费 vs 付费）也随渠道包一起没了。

**重定义三个策略，并真的接到开关上**：

| 选项 | 真的做什么 |
|---|---|
| **自备优先 → 官方兜底**（默认） | 保留 `fallback.enabled`，不动排除名单 |
| **只用自备** | 关官方兜底 **+ 把官方从渠道里排出去** |
| **只用官方** | 临时排除所有非官方渠道 |

⚠️ **`self-only` 必须两个机制都管**：官方那条现在**同时存在于** ① `gateway.fallback`（router 的老机制）和 ② **渠道列表**（它作为普通渠道挂进 allChannels）。只关 ① 的话，名义上"不用官方"、实际照样被 ② 选中 —— **一个看着生效、其实没生效的开关。**

⚠️ 排除名单是**算出来的临时值、不写回配置** —— 否则你切回别的策略时名单还留着，渠道会莫名消失。

老配置里的 `free-first` / `free-only` **自动归一**，不迁移也能跑。

## 修了：她发的收藏表情被 QQ 内置表情劫持

**现场**：
```
群友「有收藏表情怎么又在用qq表情」
表情「无语」→ 精确匹配「无语」(face 40)   ← 又发了个 QQ 内置
表情「震惊」→ 精确匹配「震惊」(face 26)
表情「疑惑」→ 按标签命中 …               ← 这次才是她收藏的
```

**根因是挑选顺序**：「无语」「震惊」这类词**既在 QQ 内置表的别名里，也是收藏表情的标签**。原来 `QQ 内置表` 排在 `收藏表情` 前面 → 永远轮不到收藏库。

改成：配置映射 → **收藏表情按标签** → QQ 内置表 → 收藏随机。

⚠️ `[表情:N]`（按编号指定 QQ 表情）走另一条路，**不受影响**。

## 面板：渠道卡片并排 + 去掉「其它渠道」

- 卡片竖排的根因是**分组容器把它挡住了**（`.gd_group` 是竖向 flex，每组占外层网格一格）→ 改成组占满整行、组内两列

## 测试这块：修了一批「看起来绿其实没测到东西」

**★ 挖出一个「假绿」——比红更糟。** `check-boot` 一直**打印了 ❌ 却退出 0**。根因：

```js
// doShutdown
logger.close()
process.exit(0)      // ← 硬编码 0
```
而它的收尾是 `await r.shutdown(...)` → **进程在这儿就结束了** → 后面的 `process.exit(fail === 0 ? 0 : 1)` **永远执行不到**。**那两条失败从来没传出来过。**
（`doShutdown` 改成尊重 `process.exitCode`；测试在收尾**之前**就打成绩。）

**其它**：
- `check-router`：代码没守自己写下的规矩（规格="按首字母排"，代码还是手排梯队）
- 4 个依赖渠道包的测试：改成**优雅跳过**（原来 `pack.file` 抛 TypeError，尾部只剩一句 `Node.js v24.20.0`，**看着像代码坏了，其实是环境缺件**）
- **删两个死文件**：`check-launcher-args` 读的 `scripts/package.mjs` **从没提交过**（git 历史为空），`check-exe-e2e` 要另一个目录的构建产物
- 加了几条**守卫**：一旦某个前提变了（比如 hint 表被填满），先红并说明"前提变了"
