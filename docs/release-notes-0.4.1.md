# WhalePod 0.4.1

一个**修 bug 的版本**。主要是三件事：B 站视频又取不到了、表情包池子太大、人格只能整体切换。

---

## 修了：B 站/贴吧/热点全部"取失败"

**症状**：她回「本鱼这边放不出来」，贴吧订阅和热点也全是 `fetch failed`。

**查出来的原因**（不是 B 站挂了）：

```
https_proxy = http://127.0.0.1:7890     ← 环境变量里有代理
NODE_USE_ENV_PROXY = 1                  ← Node 被要求走它
127.0.0.1:7890  ✗ ECONNREFUSED          ← 但代理软件已经关了
b23.tv:443      通                       ← 裸连其实没问题
```

代理软件关了，环境变量还留着，于是**所有请求都往一个死端口上撞**。而 B 站是国内站，本来就不需要代理。

**顺带还发现**：NapCat（协议端）也是 Node 应用，跟着继承了同一份变量 —— 所以那会儿**连发消息都会失败**，报的是 `connect ECONNREFUSED 127.0.0.1:7890`。

**修法**：
- 国内域名（`bilibili.com` / `b23.tv` / `hdslb.com` / `bilivideo` / 贴吧…）追加进 `no_proxy`
- **在 `main()` 最前面做** —— Node 的 fetch 在第一次调用时就建好 dispatcher，之后再改环境变量**无效**
- spawn NapCat 时**剔除**代理变量，并显式 `NO_PROXY=*`

**实测**：贴吧 30 条、`b23.tv` 短链解出 BV 号、评论弹幕全通。

⚠️ 附带一句：**`resolveBvid` 失败不再静默**了。原来它 `catch { return null }`，出问题时日志里一个字都没有，只能靠手工复现才查得出来。

## 修了：她会编"我点开是想干嘛"

**现场**：视频标题是「你爸回你消息了」，评论弹幕全在聊"大肥鱼/赛博养鱼"。她的回复：

> （看完，先笑了一声）**点开想学修电脑**，结果评论全在要饭。

「点开想学修电脑」在标题/简介/评论/弹幕里**一个字都没有** —— 纯编。

**为什么原来的警告没拦住**：它只禁"聊视频里讲了啥"。而"我点开是想学修电脑"是**编了个观看理由**，模型不觉得那算"讲内容"，而且它比"我没看过"更像聊天，所以选了它。

现在把边界说全了：**连"我点开想干嘛"也不许编。**

## 新增：表情包同类只留 3 张

收藏表情越攒越多，但**同一情绪**的图往往有十几张（"无语"一堆、"嫌弃"一堆）。池子太大会让提示词清单变长、按标签挑的时候同类互相挤。

现在：**同类最多留 3 张，留最新的**，每打完一批标签就顺手收敛一次。

**"同类"按标签组合的相似度算**（Jaccard），不是按第一个标签 —— 因为库里「无语」打头的有 14 张，但第二标签差别很大：

```
无语、愤怒、压迫感、发疯
无语、嫌弃、冷漠、看戏、死亡凝视
```

按第一个标签归类会把这 14 张当同类砍到 3 张，等于删掉明显不同的图。

**阈值 0.5 是拿真实库试跑定的**：0.4 会过度合并（把"狂笑、嘲讽"和"无语、看戏"归成一组），0.6 完全不触发。

实测：**72 张 → 69 张**。

⚠️ **只清标签库，不删表情本身** —— 图还在收藏里，只是不进提示词清单了。

## 新增：人格可以按会话生效

原来 `persona.active` 是**全局**的：切一下，群里和私聊都跟着变。

现在可以**群聊和私聊用不同角色**：

```
群聊 → default（那只嘴硬的鱼鱼）
私聊 → close（另一版）
```

查找顺序：**精确会话 → 类型（group/private）→ 全局**。

设置页「当前人格」那行现在有两个下拉：左边选**范围**（全局 / 群聊 / 私聊 / 具体某条会话），右边选**角色**，下面显示「按会话：群聊 xxx ｜ 私聊 yyy」。

⚠️ 选「**全局**」会**清掉按会话的指定** —— 不然全局那个值永远轮不到（因为精确和类型的优先级更高），看起来就像"点了没反应"。

## 其它修正

- **被点名时不再给 `[SILENT]` 出口** —— 原来被 @ 了也可以不吭声，观感是"叫它它不理"
- **别人被 @ 时不插嘴** —— 原来只要是问句就强制回答，哪怕 @ 的是另一个人
- **长期记忆不再把她某次拒绝写成"她是谁"** —— 原来摘要会写「我仍拒接荤话 / 守住界线 / 不松口」，然后下一轮她就照着继续拒绝，越写越硬
- **【人】是全局的**，所以关系类内容不再进那里（群里会露馅）
- **长视频先应一声**：超过 5 分钟的，先回一句，后台只听开头 2MB（≈前 4 分钟），听完再补一句

## 测试

新增 6 个测试文件（+729 行），其中三条是**源码锁**：

| 锁 | 守什么 |
|---|---|
| `check-proxy-bypass` | `applyDomesticBypass` 必须在 `main()` 最前 —— **挪到后面就等于没做** |
| `check-proxy-bypass` | NapCat 必须剔除那 6 个代理变量 |
| `check-persona-scope-ui` | 界面显示的 == 实际生效的（两边算法必须一致） |
| `check-sticker-dedupe` | **不能按第一个标签归类**（会把不同的图当同类删掉） |
| `check-question-gate` | @ 了别人不覆盖，但**没 @ 的普通提问照旧覆盖**（别一刀切） |
| `check-bili-longvideo` | 补发必须从 `gen.text` 取文本（`_generate` 返回的是对象） |

## 升级方式

**覆盖安装**即可，配置文件兼容。新增的配置项都有默认值。

如果想用「人格按会话」，在设置页把私聊那一档指到别的角色就行。
