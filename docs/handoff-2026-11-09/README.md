## 二、根因

1. **出图闸门缺少"私密语境"判断**
   - `bridge.js` 的出图判断只看用户这句话里有没有"拍/看/图"等词
   - 「看看你」命中"看" → 允许开画；但上下文是床上/调情 → 不该拍

2. **上游拒答没有清洗**
   - 模型对露骨内容返回拒答文本（`Sorry, I can't respond…` / `抱歉，我不能…`）
   - bridge 把它当普通正文直接发送，泄漏到聊天里

3. **画图配额（自有，非上游）**
   - `_drawQuotaCheck`：同会话 **5 分钟最多 2 张**、同描述 10 分钟去重；主图与附加图共用
   - 场景图与自拍共用同一配额；昨天的命中日志：`画图跳过 —— 这个会话 5 分钟内已画 2 张（上限 2）`
