# 交接：把交集版模板改成"绝对单手"（给 GPT）

> 任务：基于你上一版「交集版模板 A/B/C」修订，**把所有双手动作改成单手，禁止出现两只手**。
> 原因：她一个人用手机拍摄，没有支架、没有第二个人。**一只手持机在画外，画面里最多只能出现另一只动作手**；两只手同时出现在画面里，物理上不成立。

---

## 1. 新的硬规则（优先级最高）

1. **不考虑支架、不出现第三方摄影师、不出现第二个人。**
2. **画面里最多 1 只动作手**（持机手永远在画外）。
3. **禁止任何"双手/两只手/另一只手也…"的画面描述**，除非那句话是"另一只手在画外持机"。
4. 任何本质上需要两只手配合的动作（切菜、晾衣、双手抱物、双手比心、捧碗等）：
   - **必须改写成单手版本**；或
   - 改写成本身不需要手的**物品/环境照**；
   - 不允许保留双手画面。

---

## 2. 需要你（GPT）改的内容

### A. 通用模板
在上一版交集模板基础上：

4. 如需要，再加一个"单手后置拍物"样例：**一只手拿起/指向物品**（另一只手持机在画外）。

### C. 手数表（改成绝对单手）

| 场景 | 持机手 | 画面动作手 |
|---|---:|---:|
| 前置自拍，不做动作 | 1（画外） | 0 |
| 前置自拍，另一手拿杯子/提篮 | 1（画外） | 1 |
| 对镜自拍，自然垂放/整理衣摆 | 1（镜中） | 0–1 |
| 第一人称单手操作 | 1（画外） | 1 |
| 后置拍物，单手拿起/指向 | 1（画外） | 1 |

| 切菜/晾衣/双手抱物/双手比心 | — | **禁止；改写为单手或物品照** |

### D. 常见双手动作的改写清单（请你补全并给示例句）

| 原动作 | 单手改写 | 或物品/环境照 |
|---|---|---|
| 切菜（按菜+拿刀） | 一只手拿刀切砧板上平放的黄瓜（不出现按菜的手） | 砧板+刀+黄瓜，无人无手 |
| 晾衣服（拿衣架+挂衣） | 一只手把一件衣服挂上衣架/杆（衣服可先搭在杆上） | 晾衣杆+衣架+洗衣篮，无人 |

| 双手比心 | 单手比心或不做手势 | 只拍脸部/上半身 |
| 捧碗喝汤 | 一只手端碗（另一手持机画外） | 桌上一碗汤 |

**注意**：改写后仍要满足"姿势自然、动作可信"；如果单手版本明显不自然（例如切菜没有按菜手会显得假），就改成物品/环境照，**不要硬画两只手**。
