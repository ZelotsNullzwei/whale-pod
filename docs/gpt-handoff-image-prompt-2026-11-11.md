# 交接文件：鲸鱼娘生图提示词（给 GPT）

> 目的：让 GPT 基于现有「通用模板 v2」，产出**可直接喂生图模型的最终提示词**，并指出模板里仍需修改的地方。
> 你（GPT）不需要写代码，也不需要访问仓库；只需要读模板、看附件图、按要求输出文本。

---

## 1. 背景（一句话）

这是一个 QQ 机器人角色的日常照片生成。生图接口是 OpenAI 兼容的 `images/edits`，**每次上传两张参考图**：

1. **脸部参考图**：锁定长相、蓝瞳、蓝发、蕾丝发带、耳侧鳍形耳饰；
2. **身体参考图**：锁定身形比例（窄肩、细腰、窄胯、四肢纤细）。

模型**不会读本地文件路径**，所以最终提示词里不要出现任何文件路径；图片靠“上传的参考图1/2”指代。

---

## 2. 你（GPT）要产出什么

请按顺序给出三样东西：

### A. 修订后的通用模板（Markdown）
在用户提供的「通用模板 v2」基础上修订，保留其结构：
- 主体类型：`person` / `first_person` / `object` / `environment`
- 参考图用途、拍摄方式、造型、构图、场景与光线、禁止项、输出
- 每个信息只出现一次（服装只在造型、景别只在构图、场景只在场景）
- 删除不适用项，不留空括号

### B. 一个“填好并编译”的最终提示词
目标场景见第 4 节。要求：
- **直接可以粘贴进生图界面**；
- 不要带章节标题以外的占位符、不要带 `{...}`；
- 长度控制在 **900–1200 个中文字符**；
- 结构与模板一致，但删掉对模型无用的“元信息”（如 `主体类型：person` 这种英文枚举，改成一句自然语言）。

### C. 仍然解决不了的问题清单
列出 3–5 条“提示词再改也压不住、只能靠后处理/换参考图”的问题，并给建议。

---

## 3. 必须遵守的硬约束

### 人物
- 成年女性；蓝瞳（清澈、可辨的蓝）；蓝色长卷发、齐刘海、头顶一缕呆毛；白色蕾丝发带。
- 耳侧各有小巧的深蓝配白色**鳍形耳饰**：贴耳、向外张开、薄片状、不超过耳朵、不遮脸颊；不是猫耳/发卡/蝴蝶结/大翅膀。
- 身形：窄肩、薄背、细腰、窄胯，四肢纤细；轻微自然曲线，不夸张；胸部平缓克制、左右对称。
- **不要写具体围度/罩杯数字**（模型会用数字放大某处），只写体态气质。

### 参考图
- 两张都上传、都使用；**脸部参考优先于身体参考**。
- 参考图只用于人物身份/身形；**不要照搬参考图里的衣服、姿势、背景、表情、光线**。
- 身体参考图里是白背心+短裤，必须在提示词中明确“不要照穿”。

### 拍摄物理
- 前置自拍：手机和持机手在画面外；最多一条持机手臂从边缘伸入；另一只手可提篮子/扶东西。
- 对镜自拍：必须真的有镜子；镜中能看到手机和持机手；只有一个正确反射。
- 后置拍物/环境：人物、手、倒影都不出现。
- 不要第三方摄影师、不要第二台设备、不要自拍杆（非架机模式）。

### 构图
- **每张只选一个景别**：头肩/半身到腰/半身到胯/全身/局部/环境照。
- 选“半身到腰”时，**不要再描述裤子下段、袜子、鞋**；不要又要求全身。
- 选“全身”时，鞋要完整、保留地面。

### 文字
- 价签、包装、屏幕上的文字：**保持模糊、不可读**；不生成清晰可读的中文/英文。

### 输出
- 竖版 9:16，单张，真实生活摄影。
- 比例只在“输出”写一次。

## 4. 本次要编译的场景（示例，按这个填）

- 主体：人物本人自拍（`person`）
- 地点：小区门口的生活化小超市，货架和冷柜前
- 时间/光线：傍晚，超市暖色环境光 + 入口斜照的暖黄夕阳
- 动作：一只手提小购物篮；另一只手持机在画外；刚看完价签，自然抬头，视线落在镜头旁
- 服装：白色蕾丝发带、藏青 V 领毛衣、翻出的白衬衫领、米白直筒长裤、白棉袜、白色帆布鞋
- 发型：披散，出门前梳过，有几缕碎发
- 景别：**半身到腰**
- 禁止：手机/镜子/第三方/其他人/额外手脚/夸张胸臀/清晰价签文字

---

## 5. 具体步骤（请按此顺序做）

1. **读模板**：先确认主体类型和拍摄方式，只保留对应片段。
2. **填占位**：把场景、服装、发型、景别、表情、光线填进去；不适用项删除。
3. **去重**：检查服装是否只在造型出现一次、景别是否只有一个、比例是否只在输出出现。
4. **改写成自然语言**：删掉 `{SUBJECT_MODE}` 这类枚举和章节空标签；把“主体类型”变成一句“这张是人物本人用手机前置摄像头拍的自拍”。
5. **压缩到 900–1200 字**：合并重复禁止项；删掉对本次画面无用的模块（如拍物图里的人物身份）。
6. **自检**：对照第 6 节清单逐条打勾。
7. **输出 A/B/C 三样**。

## 6. 验收清单（出图后人工检查）

- [ ] 脸和蓝瞳与参考图一致，没有变成黑瞳/棕瞳
- [ ] 白蕾丝发带、耳侧鳍形耳饰都在，且不是猫耳/翅膀
- [ ] 服装与指定完全一致：藏青 V 领毛衣 + 白衬衫领 + 米白长裤 + 白帆布鞋
- [ ] 只有提篮子的手可见；持机手/手机不在画面
- [ ] 没有镜子、没有第二个人、没有第三方视角
- [ ] 景别符合（半身到腰，不出现鞋/小腿）
- [ ] 价签/包装文字模糊不可读
- [ ] 没有多余手指、重复手臂、畸形手
- [ ] 没有夸张胸臀、左右不对称

---

## 7. 已知模型限制（提示词压不住的）

1. **半身构图**：写了“半身到腰”，模型仍可能画全身/鞋 → 建议生成后按腰线硬裁。
2. **价签文字**：写了“模糊不可读”，仍可能生成乱码中文 → 建议后处理模糊或场景不放价签。
3. **参考图衣服污染**：身体参考是白背心短裤，即使写了“不要照搬”，仍可能把版型带进来 → 必要时只喂脸参考（但身形会飘）。
4. **手数**：写了“只出现提篮手”，仍可能多画一只手 → 出图后检查，必要时重生成。
5. **发型/配饰漂移**：发带、耳饰、发色需要靠参考图 + 明确文字双重约束。
