# 通用出图提示词模板（v1）

> 用法：先选 `{SUBJECT_MODE}`，再填 6 个空：`{SCENE}`、`{LIGHT}`、`{OUTFIT}`、`{HAIR}`、`{FRAMING}`、`{EXPRESSION}`。
> 规则：**同一件事只写一次**——衣服只在【生活状态】写，场景里不再重复；景别只写一个，不要"半身+全身"。

---

## 一、固定部分（所有模式通用）

```text
【画风】
真实生活摄影，像手机随手拍到的日常照片。自然光与真实环境光，合理的景深和透视，轻微生活噪点；不要插画、动漫、3D渲染或影棚摆拍感。
```

## 二、按主体类型选择

### A. `person`（人物本人入画：自拍 / 对镜 / 摆拍）

```text
【参考图与人物】
使用本次上传的参考图，表现同一个人物：
- 脸部参考图：保持人物身份、脸型、五官比例、眼睛颜色、发色、发型、发带和耳饰。
- 身体参考图：只参考身形和体态。
- 两张图冲突时，脸部参考图优先。
- 不要照搬参考图中的衣服、姿势、表情、背景或光线。

保持脸型与五官比例一致，瞳孔清澈、明确可辨地呈蓝色。蓝色长卷发、齐刘海，头顶正中一缕翘起的呆毛；白色蕾丝发带。{HAIR}
两侧耳边都有小巧的深蓝配白色鲸鱼鳍形耳饰：贴耳、向外张开、薄片状、不超过耳朵、不遮脸颊；不是猫耳、发卡、蝴蝶结、鱼鳍披风或大翅膀。
身形：窄肩、薄背、细腰、窄胯，四肢纤细自然；有轻微自然曲线但不过分突出，胸部轮廓平缓克制、左右对称；不要完全平板，也不要夸张沙漏型。

【生活状态与服装】
服装固定为：{OUTFIT}。不要增删、替换或重新设计单品。
{FRAMING}；画面只展示该景别内的衣物，未入画的下装/鞋不作为画面要求。
```

### B. `first_person`（第一人称：只有手/腿/局部，不出现人物）

```text
【人物局部】
只出现完成当前动作所必需的手/手臂（必要时腿/脚）；不出现脸、头发、肩膀、躯干。
入画的手必须是同一个人：皮肤偏白、真实质感；手指修长、指节清楚、指甲短而平整。

【生活状态】
{OUTFIT}（只写实际会入画的衣物；没入画的不要写）
```

### C. `object`（后置拍物：物品是唯一主体）

```text
【主体】
{OBJECT_SUBJECT}
这是本张唯一的主要主体，物品清晰、占据主要构图区域。

【人物排除】
画面不出现人物、人物倒影或身体局部；默认不出现手。
只有明确要求“拿起/翻动/指向/操作物品”时，才允许出现执行该动作所必需的手。
```

### D. `environment`（后置环境/天气/空间）

```text
【主体】
{ENVIRONMENT_SUBJECT}
画面主体是指定环境/天气/空间，不出现人物。

【天气可视化】
只使用已知天气能支持的可见线索（风→窗帘/树叶；雨→雨滴/湿润；阴→漫射光；晴→明亮）。没有依据就不加天气现象。

【人物排除】
不出现人物、人物倒影、身体局部、手或手臂；不出现旁观者或摄影师。
```

## 三、拍摄动作片段（按模式选一个）

### 前置自拍

```text
【拍摄动作】
这是人物用自己的手机前置摄像头拍摄的自拍，镜头朝向她本人，距离约一臂，略高于脸部。
一只手臂从画面边缘自然向镜头方向伸出，负责持手机；**持机手和手机本体都在画面外**。
另一只手自然放松，或做当前场景需要的一个简单动作（如提篮子/扶杯子）。
画面里最多出现两条手臂，不要额外手掌、手指或重复肢体。
```

### 对镜自拍

```text
【拍摄动作】
场景中必须存在一面真实镜子；人物站在镜前，用手机后置摄像头对着镜子拍摄。
镜中应能看到人物和正在使用的手机；手机由一只手真实握持，手机背面朝向镜子。
镜中只出现同一个人物的一份正确反射，不得出现第二张脸、重复身体或额外手臂。
另一只手按姿势自然下垂或做一个简单动作。
```

### 后置拍物

```text
【拍摄动作】
拍摄者是人物本人，使用手机后置摄像头拍摄眼前物品。
相机视点位于手持手机的后置镜头处，镜头朝向被拍物；手机本体、持机手和人物身体都不进入画面。
不是第三方从房间另一侧拍摄人物。
```

### 后置环境

```text
【拍摄动作】
拍摄者是人物本人，使用手机后置摄像头拍摄眼前环境。
相机视点位于手持手机的后置镜头处，镜头朝向环境主体；手机、持机手、人物身体都不进入画面。
不要为了表现“有人在这里”而添加人物、身体局部或倒影。
```

### 第一人称

```text
【拍摄动作】
镜头位于人物双眼/胸口高度，朝向她正在做的事；只出现动作需要的手/手臂，另一只手在画外。
不要从侧面伸手、不要出现第二张手、不要出现任何人的脸/身体/肩膀。
```

## 四、构图与表情

```text
【摄影方案与构图】
竖版 9:16，单张。{FRAMING}——只保留这一个景别，不要再叠加其他景别。
镜头距离与角度符合真实手机拍摄：{CAMERA_ANGLE}。
{FRAMING_RULE}
不要出现第三方机位、镜子（对镜模式除外）、自拍杆或第二台设备。

【表情与视线】
{EXPRESSION}
表情、视线、头部和身体姿态彼此协调，不要证件照式僵硬正脸，也不要刻意冷脸/摆拍微笑。
```

`{FRAMING}` 建议值：
- `半身到腰` → 画面包含脸、肩、上半身，裁切到腰附近；下装/鞋不出现
- `半身到胯` → 可看到腰胯，但膝盖以下不出现
- `全身` → 从头到脚，保留地面空间；鞋要完整
- `头肩/面部特写` → 头顶到胸口或更近
- `局部` → 只框住指定部位
- `环境照` → 以空间/物品为主，人不在画面里

## 五、场景与光线（每次只填这两格）

```text
【场景与光线】
{SCENE}
{LIGHT}

画面只出现指定人物/物品/环境，不出现朋友、家人、摄影师或其他人物。
场景中的价签、包装、屏幕等文字保持模糊、不可读，不生成清晰可读的文字。
```

## 六、通用禁止 + 模式追加

```text
【禁止】
- 不要改变人物脸型、五官比例、蓝瞳、蓝长卷发、齐刘海、呆毛、发带或耳侧鳍形耳饰。
- 不要遗漏耳饰，也不要画成猫耳、发卡、蝴蝶结、鱼鳍披风或大翅膀。
- 不要照搬参考图中的衣服、姿势、表情、背景或光线。
- 不要出现其他人物、额外手臂、额外手掌、畸形手指或重复肢体。
- 不要出现水印、文字叠加、界面截图、拼贴感、二次元、Q版、低龄化或 3D 渲染。
{MODE_BANS}
```

`{MODE_BANS}` 追加：
- 前置自拍：`不要手机入画、不要镜子、不要第三方机位、不要俯拍/广角拉伸`
- 对镜自拍：`不要出现第二份反射、不要手机屏幕和背面同时可见`
- 后置拍物：`不要出现人物/倒影/手（除非明确操作）`
- 后置环境：`不要出现人物、手、倒影、衣服`
- 第一人称：`不要出现脸/身体/第二个人、不要从侧面伸手`

## 七、输出

```text
【输出】
竖版 9:16，单张真实生活摄影风格图片。
```

## 八、填空示例（同一个模板，换成不同场景）

| 空 | 超市自拍 | 在家吃面 | 窗外下雨 |
|---|---|---|---|
| `{SUBJECT_MODE}` | person | first_person | environment |
| `{SCENE}` | 小区门口小超市，货架和冷柜前，手提购物篮 | 家里小厨房，桌上放着一碗面 | 客厅窗户，玻璃上有雨滴 |
| `{LIGHT}` | 傍晚暖黄环境光 + 夕阳斜照 | 中午自然光，稍硬 | 阴天漫射光，低对比 |
| `{OUTFIT}` | 藏青 V 领毛衣 + 白衬衫 + 米白长裤 + 白帆布鞋 | （只写会入画的袖子） | —（environment 不写） |
| `{FRAMING}` | 半身到腰 | 局部（手+碗） | 环境照 |
| `{EXPRESSION}` | 刚抬头，视线落在镜头旁 | —（不出现脸） | —（不出现人） |
