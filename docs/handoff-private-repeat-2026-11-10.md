- 两条回复 id 不同、两个输入也是不同 id → **两次独立生成/发送**，排除 OneBot 重复投递。
- 前两段逐字相同，只有第三段的括号动作不同 → **跨轮复用上一轮模板**。

## 2) 根因（代码）

| 位置 | 事实 |
| --- | --- |
| `bridge.js _stripSelfRepeat` | 只处理**同一条文本内部**的句子重复，不跨轮 |
| `bridge.js _lastBotText` | 存最近一条（≤200 字），只用于拼 ctx，不参与去重 |
| `bridge.js recentSelf`（提示词） | 给了最近 3 条自己的话，但没有"别和上一条同开头"的硬规则 |

## 3) 修复（已上线）

- 回归：`tests/check-cross-turn-repeat.mjs`（7 项，含事故原句、不同会话隔离、兜底）。
