# 双手动作 → 单手/物品照：优化方法（2026-11-11）

## 最终定稿规则（2026-11-11 用户确认）

1. **双手动作**（切菜、洗菜、洗碗、洗衣、晾衣、端托盘等）→ 一律走 **后置拍物 `rear_selfie` + `subjectMode=object` + `sceneOnly`**：画面只有砧板/食材/工具/台面等物品，**0 手、无人物**。提示词按"厨房切菜 object"那份范本写：主体、物品状态、环境细节、轻微生活杂乱、自然光、9:16；负向明确"不要人物/手/倒影/手机/水印"。
2. **有镜子或自拍的情况** → 按 **抱枕范本**：画面只出现 **1 只动作手**（抱枕/拿东西），另一只手持机在画外；对镜时镜中持机手是反射必需，不算动作手。
3. 女款服装/体态全局生效；洗衣/晾衣物品照只用不透明女款家居服（蕾丝边、碎花、针织），禁止内衣/透明衣物。
4. **人物图一律先出全身底图**（头顶到脚、鞋完整、两条腿两只脚）；需要半身/头像时，**从同一张全身底图单独裁**，不要让模型重新画半身/腰胯。

> **重要纠正（用户 2026-11-11）**：不存在"支撑手"。她另一只手永远在画外**拿着手机**，不是备用支撑手。
> 所以不是"把支撑手移走"，而是：**动作必须本来就只需要这一只手；需要第二只手参与的动作，直接不拍手。**
> 画面中的那 1 只动作手必须能**独立完成**动作——物品已被环境固定（放稳、挂好、穿好、在容器里），不需要扶/托/按/拿。

> 目标：她一个人手持手机，画面里最多只能有 1 只动作手（持机手在画外）。
> 原则：**先改动作结构，再改提示词**。不要靠"不要画另一只手"这种否定句。

## 单帧规则（2026-11-11 用户确认）

> 照片是**单帧**，不是视频：动作不需要做完，也不需要"单手能独立完成"。
> 画面只出现一只动作手；另一只手在画外拿着手机。动作可以停在半途，只要这一帧自然、不穿帮。

**切菜的正确写法（范本）：**
```text
第一人称视点。一只手在画外拿手机拍摄；画面里只出现一只动作手——这只手只拿菜刀，
刀停在砧板上平放的黄瓜上方/正在下刀。黄瓜平放在砧板上，不需要另一只手按。
不出现按菜的手，不出现手机、持机手或第二只手。
```
> 切菜动作在现实中做不完（另一只手在拿手机），但这不影响照片成立；照片只记录这一帧。

**抱枕/自拍范本：**
```text
前置自拍：一只手把枕头抱在身侧（画面里可见这只手/手臂）；
另一只手举着手机，在前置自拍里位于画外。
画面里的动作手只有抱枕那只，不出现第二只动作手。

对镜自拍：镜中会看到举手机的手（镜面反射必需，不算动作手）；
抱枕手仍是唯一动作手。若不想画面出现两只手，就把枕头搭在身侧/垫在背后。
```

## 1. 三步判断

### 第 1 步：这个动作需要几只手？
- **0 只**：物品/环境照（不出现人物、手）。
- **1 只**：可以保留单手，持机手在画外。
- **2 只**：进入第 2 步。

### 第 2 步：能否把"支撑手"的工作移走？
二只手通常分成"操作手 + 支撑手"。只要支撑手能移走，就能变单手：
- 支撑物固定在桌面/砧板/架子/夹子上；
- 或换成不需要支撑的工具（夹子、挂钩、篮子、支架——但本模板不用支架拍人，只用于固定物品）；
- 或把"支撑"改成"已经放好"的状态（衣服已挂上、鞋已穿好、书已摊开）。

**能移走 → 单手版本**；移走后动作明显假 → 第 3 步。

### 第 3 步：单手版本不自然 → 拍物品/环境
不出现手，只拍痕迹：
- 切菜 → 砧板 + 刀 + 切好的菜；
- 晾衣 → 晾衣杆 + 衣架 + 衣服；
- 洗碗 → 水槽 + 泡着的碗 + 海绵；
- 抱枕 → 床上的枕头；
- 捧碗 → 桌上的碗；
- 翻书 → 摊开的书；
- 穿鞋 → 地上的鞋；
- 抱花 → 花瓶里的花。

**如果人物必须入画**：拍静态自拍（手自然垂放/整理衣摆），动作写在说说文案里，不在画面演。

## 2. 单手改写公式

一句话结构：

```text
【动作】画面只出现一只手：这只手{操作动作}。
{被操作物}已经稳定放在{位置}/已经{状态}，不需要另一只手扶、托、按或拿。
另一只手持机在画外，不出现。
```

示例：
- 切菜：`一只手持刀切砧板上已放稳的黄瓜；黄瓜不需要按住。`
- 晾衣：`一只手把已挂在晾衣杆上的衣服理平；衣服已经在杆上。`
- 洗碗：`一只手持海绵擦水槽里已放稳的碗；碗不需要另一只手扶。`
- 翻书：`一只手捏住一本已摊开在桌面的书的单页翻页。`
- 穿鞋：`一只手拉已穿在脚上的鞋的鞋舌；脚和鞋保持不动。`

> 如果这句话读起来像"这个动作现实中做不了"，就不要写手，直接物品照。

## 4. 可信度自检（写完逐条问）

1. 另一只手的工作是否真的移走了？（物已固定/已放好/已穿好）
2. 画面里是否只描述 **1 只动作手**？
3. 有没有"两只手/双手/另一只手也…"这种词？有就删。
4. 这个单手动作现实中做得出来吗？（比如"一只手切没有按住的黄瓜"能，但"一只手拧毛巾"不能）
5. 做不出来 → 改成物品照，不要硬画。

---

## 5. 测试结论（本地已跑）

- ✅ 单手端杯、单手拿马克杯：成立，只有 1 只手；
- ⚠️ 单手切菜：能出图，但刀/手关系略悬；优先改物品照；
- ✅ 晾衣/洗衣物品照（女款衣物）：成立，无人无手；
- ✅ 抱枕物品照：成立；
- 结论：**双手动作优先走物品照；只有真正自然的单手动作才保留手。**

---

## 6. 一句话原则

> 不是"把两只手删成一只"，而是"让另一只手不需要存在"。做不到，就不拍手。
